# Rekomendasi Stack Website

Kebutuhan: website publik (beberapa halaman) + **dashboard admin** untuk mengubah harga, data tukang potong (barber), dan ulasan. Karena itu perlu backend, database, login admin, dan penyimpanan foto.

## Pilihan utama: Next.js + Supabase
| Bagian | Pilihan | Alasan |
|---|---|---|
| Framework | **Next.js (App Router)** | Website publik dan dashboard admin dalam satu project. Halaman publik tetap cepat dan bagus untuk SEO |
| Styling / UI | **Tailwind CSS + shadcn/ui** | Slicing cepat. shadcn/ui sudah punya tabel, form, dan dialog untuk dashboard |
| Database | **Supabase (PostgreSQL)** | Gratis untuk tahap awal dan punya tampilan tabel bawaan untuk cek data |
| Login admin | **Supabase Auth** (email + password) | Hanya pemilik atau admin yang bisa masuk ke `/admin` |
| Upload foto | **Supabase Storage** | Untuk foto barber, galeri, dan pricelist |
| Validasi form | **Zod** + Server Actions | Input harga atau data lain dicek di server sebelum disimpan |
| Booking | Link `https://wa.me/6287831108342?text=...` | Tetap lewat WhatsApp, tanpa sistem antrean |
| Peta | Embed Google Maps (iframe) | Gratis, tanpa API key |
| Hosting | **Vercel** | Gratis, deploy otomatis dari GitHub |
| Domain | `.com` atau `.id` | Sekitar Rp150–300 ribu per tahun |

## Halaman
- **Publik:** Beranda, Layanan & Harga, Barber, Galeri, Ulasan, Kontak/Lokasi
- **Admin (`/admin`, wajib login):**
  - Harga: tambah, ubah, hapus layanan, atur urutan, sembunyikan atau tampilkan
  - Barber: nama, foto, keahlian, status aktif
  - Ulasan: input manual atau import, lalu pilih mana yang ditampilkan
  - Info toko: jam buka, nomor WhatsApp, alamat, link sosmed

## Tabel database (awal)
| Tabel | Kolom utama |
|---|---|
| `service_categories` | id, nama (Potong Rambut / Perawatan / Styling & Produk), urutan |
| `services` | id, category_id, nama, harga, harga_mulai (bool, untuk "start from"), aktif, urutan |
| `barbers` | id, nama, foto_url, keahlian, aktif, urutan |
| `reviews` | id, nama, rating, teks, tanggal, sumber (google/manual), tampil (bool) |
| `settings` | jam_buka, whatsapp, alamat, instagram, tiktok, maps_url, rating_google, jumlah_ulasan |

Data awal (seed) diambil dari catatan ini: 17 layanan dan 20 ulasan Google.

## Alternatif
- **Laravel + Filament** (PHP): dashboard admin jadi sangat cepat dibuat. Cocok kalau tim lebih biasa pakai PHP. Hosting-nya di VPS atau shared hosting.
- **Next.js + Prisma + PostgreSQL di Neon/Railway + Auth.js**: lebih fleksibel, tapi login dan upload foto harus disusun sendiri.
