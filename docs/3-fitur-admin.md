# Fitur Admin (Dashboard `/admin`)

Prioritas: **[MVP]** = versi pertama, **[Nanti]** = setelah website jalan

## Akses
- [MVP] Login email + password (Supabase Auth), hanya akun admin yang boleh masuk
- [MVP] Logout dan lupa password
- [Nanti] Banyak admin dengan peran berbeda (owner, staff)

## Layanan & Harga
- [MVP] Tambah, ubah, hapus kategori dan layanan
- [MVP] Ubah harga, tanda "mulai dari", aktif/sembunyikan
- [MVP] Atur urutan tampil
- [Nanti] Riwayat perubahan harga

## Barber
- [MVP] Tambah, ubah, hapus barber: nama, foto (upload), keahlian
- [MVP] Status aktif/nonaktif dan urutan tampil

## Ulasan
- [MVP] Tambah ulasan manual (nama, bintang, teks, tanggal, sumber)
- [MVP] Pilih ulasan yang tampil di website (tampil/sembunyi) dan tandai unggulan untuk beranda
- [MVP] Ubah rating Google dan jumlah ulasan secara manual
- [Nanti] Sinkron otomatis dari Google Places API

## Galeri
- [MVP] Upload, hapus, dan atur urutan foto (Supabase Storage)

## Pengaturan Toko
- [MVP] Jam buka, nomor WhatsApp, alamat, link Maps/Instagram/TikTok
- [MVP] Template pesan WhatsApp untuk booking
- [Nanti] Pengumuman atau banner promo, mode libur

## Dashboard
- [MVP] Ringkasan: jumlah layanan aktif, barber aktif, ulasan tampil
- [Nanti] Statistik pengunjung dan jumlah klik tombol WhatsApp
